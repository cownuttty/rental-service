# Lab 2: контейнеризация и микросервисная архитектура

Проект разбит на два независимых сервиса:

- `rental-api/` — собственники, квартиры, клиенты, бронирования (порт 5000)
- `cleaning-service/` — горничные и задачи на уборку (порт 5001)

Оба сервиса находятся за nginx-шлюзом (`nginx/`), который слушает порт 8081
и проксирует:
- `/api/*` -> rental-api
- `/cleaning/*` -> cleaning-service

Запуск: `docker compose up -d --build`

См. подробную методичку ЛР №2.
