# Сервис аренды посуточных квартир

REST API управляющей компании, которая сдаёт квартиры собственников посуточно.
Участники: **собственники** квартир, **управляющая компания** (посредник, удерживает
комиссию), **клиенты** (арендаторы) и **горничные**.

Стек: Python 3 · Flask · SQLite · unittest/pytest · Jenkins (CI/CD).

## Сущности

| Сущность | Таблица | Описание |
|---|---|---|
| Собственник | `owners` | владелец квартир, процент комиссии УК |
| Квартира | `apartments` | принадлежит собственнику, цена за ночь, вместимость |
| Клиент | `clients` | арендатор |
| Горничная | `cleaners` | сотрудница по уборке |
| Бронирование | `bookings` | квартира + клиент + даты, стоимость считает сервер |
| Задача на уборку | `cleaning_tasks` | уборка квартиры после выезда, исполнитель — горничная |

## Эндпоинты (CRUD)

Для каждой сущности: `POST /<ресурс>`, `GET /<ресурс>`, `GET /<ресурс>/<id>`,
`PUT /<ресурс>/<id>`, `DELETE /<ресурс>/<id>`.

Ресурсы: `/owners`, `/apartments`, `/clients`, `/cleaners`, `/bookings`, `/cleaning-tasks`.
Итого **30 CRUD-операций**.

Дополнительно:

* `GET /health` — проверка работоспособности;
* `GET /apartments/<id>/availability?check_in=YYYY-MM-DD&check_out=YYYY-MM-DD` — свободна ли квартира;
* `GET /owners/<id>/report` — доход собственника, комиссия УК и сумма к выплате.

## Бизнес-правила

* даты бронирования не должны пересекаться (заезд в день выезда предыдущего гостя разрешён);
* число гостей не больше вместимости, квартира на ремонте (`maintenance`) не бронируется;
* стоимость = число ночей × цена за ночь (считает сервер);
* нельзя удалить собственника с квартирами, квартиру или клиента с бронированиями;
* при завершении бронирования (`status = completed`) автоматически создаётся задача на уборку;

## Запуск локально

```bash
python -m venv venv
venv\Scripts\activate            # Windows   (Linux/macOS: source venv/bin/activate)
pip install -r requirements-dev.txt
python run.py                     # http://localhost:5000
python scripts/demo.py            # заполнить демо-данными через API
```

## Тесты

```bash
python -m pytest                  # или: python -m unittest discover -s tests -t .
```

## CI/CD

`Jenkinsfile` описывает pipeline: Setup → Lint → Test для всех веток,
а для ветки `main` дополнительно Package → Deploy.
